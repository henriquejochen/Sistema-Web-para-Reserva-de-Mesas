# Escopo e requisitos

## Problema

Reservas feitas apenas por telefone ou mensagem podem gerar demora, perda de informações e conflitos de horário.
Cliente diz que atualmente as reservas são feitas todas por Whatsapp, oque dificulta a organização.

## Público-alvo

- Clientes que desejam reservar uma mesa antecipadamente;
- Funcionários responsáveis pela organização das mesas e reservas.

## Requisitos funcionais

- RF01 — O cliente deve consultar disponibilidade por data, horário e quantidade de pessoas.
- RF02 — O cliente deve cadastrar seus dados para realizar uma reserva.
- RF03 — O sistema deve registrar e apresentar a confirmação da reserva.
- RF04 — O cliente deve consultar e cancelar reservas futuras.
- RF05 — O administrador deve cadastrar, editar e inativar mesas.
- RF06 — O administrador deve visualizar e atualizar reservas.
- RF07 — O sistema deve impedir conflito de horário para a mesma mesa.
- RF08 — O sistema deve respeitar a capacidade da mesa.

## Requisitos não funcionais

- RNF01 — A interface deve funcionar em celulares e computadores.
- RNF02 — Senhas devem ser armazenadas de forma segura, nunca em texto puro.
- RNF03 — As operações devem apresentar mensagens claras de sucesso ou erro.
- RNF04 — A interface deve possuir contraste, rótulos e navegação compreensíveis.
